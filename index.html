Специализируюсь на NLP и LLM: проектирую и разрабатываю AI-агентов для прикладных бизнес-задач — от прототипа до интеграции в backend. Опираюсь на понимание архитектур Transformer, embeddings и self-attention при выборе модели и построении пайплайнов.

Разрабатываю логику агентов на LangGraph и LangChain: agentic loop, паттерны ReAct и workflow-графы, tool calls и связку с сервисами через API. Собираю и оптимизирую RAG-модули (классический и agentic): векторный поиск, chunking, управление контекстом через prompt engineering и context engineering.

Работаю с LLM API, inference (vLLM), дообучением и квантизацией моделей; опыт в speech NLP (Whisper, diarization). Ускоряю цикл «идея → работающий агент» с Cursor и Claude Code. Стек: Git, Docker, SQL, FastAPI, PyTorch, Airflow.

Также занимался классическим ML: разработал recsys на основе content-based подхода.

Личный проект

ASR service
2026

Разработал full-stack веб-сервис для автоматического распознавания речи и определения спикеров в аудиозаписях длительностью до 2–3 часов. Сервис оптимизирован для работы на CPU без GPU с ограничением в 8 ГБ оперативной памяти.

Ключевые задачи и решения:

  • спроектировал и реализовал backend на FastAPI с асинхронной обработкой задач и потоковой передачей прогресса через Server-Sent Events (SSE)
  • построил пайплайн обработки на базе faster-whisper (транскрибация) и Silero VAD (диаризация), применив последовательную загрузку/выгрузку моделей для снижения пикового потребления памяти на ~40%
  • реализовал лёгкую альтернативу pyannote.audio: связку VAD + извлечение MFCC-признаков + кластеризацию (scikit-learn) с автоматической оценкой качества разделения спикеров (silhouette score)
  • разработал фронтенд с drag-and-drop загрузкой, прогресс-баром и таймером обработки в реальном времени
  • добавил экспорт результатов в форматы TXT, SRT и JSON
